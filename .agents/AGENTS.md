# Custom Workspace Rules for FitAI

This file defines critical rules that all AI developers and code-generation subagents must follow without exception.

## 1. Nutritional Macros Rule (The Fiber Rule)
* **Rule:** **Fiber** is a first-class nutritional metric in FitAI. It must never be omitted, commented out, or forgotten in any user interface, canvas sharecard, data payload, database operation, or API call.
* **Standard Macro Structure:** Wherever macros are displayed or handled, there must always be four key metrics:
  1. **Protein**
  2. **Carbohydrates (Carbs)**
  3. **Fats**
  4. **Fiber**
* **Aesthetic Standard:** The macro layouts must always split into a 4-column or 4-row layout (not 3). When using custom colors:
  * **Protein:** Orange (`#F97316`)
  * **Carbs:** Light Blue / Cyan (`#38BDF8` / `#0891B2`)
  * **Fats:** Yellow / Amber (`#FBBF24` / `#EAB308`)
  * **Fiber:** Green / Emerald (`#34D399` / `#10B981`)
